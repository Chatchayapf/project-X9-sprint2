# Sprint 2: การแบ่งงานโปรเจกต์ (Project Roles)

| สมาชิก | หน้าที่รับผิดชอบ | Branch | สิ่งที่ทำ | ผลลัพธ์ |
| :--- | :--- | :--- | :--- | :--- |
| **คุณกี** (คนที่ 1) | วางรากฐานและโครงสร้างหลักของแอป | `feature/core-setup` | สร้างไฟล์ตั้งต้นและโครงสร้างหลักที่ทุกหน้าต้องใช้ร่วมกัน<br> - `App.jsx`: จัดการระบบ Routing (การเปลี่ยนหน้า)<br> - `index.css`: ไฟล์จัดการ CSS แบบ Global<br> - `Layout.jsx`: โครงสร้างหน้าเว็บหลัก<br> - `CartContext.jsx`: ระบบจัดการ State ของตะกร้าสินค้าตรงกลาง | ทำให้โปรเจกต์มีโครงร่างเว็บที่พร้อมใช้งาน มีระบบจัดการหน้า (Routing) และระบบตะกร้าสินค้าส่วนกลางรอให้คนอื่นมาเชื่อมต่อ |
| **คุณฝน** (คนที่ 2) | สร้างส่วนหัวและส่วนท้ายของเว็บ | `feature/navbar-footer` | สร้างแถบเมนูนำทางและส่วนข้อมูลด้านล่าง<br> - `Navbar.jsx`: แถบเมนูด้านบน (โลโก้, เมนู, ตะกร้าสินค้า)<br> - `Footer.jsx`: ข้อมูลส่วนล่างสุดของเว็บ (ที่อยู่, ติดต่อ) | ทำให้เว็บไซต์สามารถนำทางไปยังหน้าต่างๆ ได้ โดย 2 ส่วนนี้มักจะถูกนำไปวางไว้ใน `Layout.jsx` เพื่อให้แสดงในทุกหน้า |
| **คุณปอ** (คนที่ 3) | จัดการหน้าแรก | `feature/homepage` | สร้างหน้า Landing Page เพื่อดึงดูดผู้ใช้งาน<br> - `HomePage` ที่รวม Component ย่อย เช่น `HeroBanner`, `ImageMarquee`, `CTAs` (ช้อปเลย), และ `Contact` | จะได้หน้าแรกของเว็บไซต์ที่สวยงามและสมบูรณ์ พร้อมต้อนรับผู้ใช้งานและนำทางไปยังส่วนซื้อขาย |
| **คุณแบงค์** (คนที่ 4) | จัดการระบบแคตตาล็อกสินค้า | `feature/products` | สร้างส่วนแสดงผลสินค้าทั้งหมด<br> - หน้า `AllProductsPage` และหน้า `Detail`<br> - `ProductGrid` สำหรับแสดงผลสินค้าเป็นตาราง/กริด<br> - จัดการโฟลเดอร์ `data/` (Mock data) | ผู้ใช้งานจะสามารถคลิกเข้ามาดูรายการสินค้าทั้งหมด ดูรายละเอียดสินค้าแต่ละชิ้น และเห็นรูปภาพ/ราคาได้ |
| **คุณธานอส** (คนที่ 5) | จัดการระบบสมาชิก, การชำระเงิน และหน้าอื่นๆ | `feature/auth-checkout` | ทำหน้าเว็บที่เกี่ยวกับการทำธุรกรรมและบัญชีผู้ใช้<br> - เข้าสู่ระบบและสมัครสมาชิก (`SignIn`, `SignUp`)<br> - สรุปการสั่งซื้อและชำระเงิน (`Checkout`)<br> - สั่งทำสินค้าพิเศษ (`CustomOrder`)<br> - หน้าแจ้งข้อผิดพลาด (`NotFound` หรือหน้า 404) | เว็บไซต์จะสามารถรับการลงทะเบียนผู้ใช้ สามารถให้ลูกค้ายืนยันการสั่งซื้อสินค้าในตะกร้าได้ และมีหน้าแจ้งเตือนเมื่อเข้า URL ผิด |
